# Sport News

Современный адаптивный веб-сайт спортивных новостей, разработанный с использованием React и Vite.

## О проекте

Sport News - frontend-проект, созданный на основе дизайна из Figma.

Проект демонстрирует работу с React-компонентами, адаптивной вёрсткой, семантическим HTML, BEM-методологией и интерактивными элементами интерфейса.

## Основные возможности

- Адаптивная вёрстка
- Навигация и поиск
- Категории спорта
- Новостные карточки
- Таблица рейтинга футбольных клубов
- Интерактивная пагинация
- Форма подписки на рассылку

## Используемые технологии

- React
- JavaScript
- Vite
- React Router
- CSS3
- Font Awesome
